# Measured original line and editable block graph

The Build workspace now connects current CPU measurements to the personal profile editor. For the selected LoRA, the original effective-update norms form a distinct dashed line; bars show `abs(model_strength * multiplier) * original_norm`. All 58 exact signed loader multipliers occupy one aligned, horizontally scrolling row. Original measurements are never substituted into editable values or exported CSV.

Open variants/history, prepare the saved stack and run **Measure current sources** in Compare & experiment. Returning to Build shows the measured graph. Without a matching measurement and current Default lineage, the existing multiplier chart remains clearly labelled; no original measurement is invented from header presence or legacy tensor norms. Original norms remain a labelled display reference during drafts and personal version changes within that Default lineage. Refreshing the library clears the reference; a different Default/slot mapping or failed preparation cannot use it. This package does not yet automatically recover numerical measurements when reopening the workspace.

Numeric edits and vertical bar dragging create ordinary personal drafts through the existing editor. Dragging inverts the contribution scale into a multiplier and preserves the current multiplier sign. Negative multipliers are striped and marked. The original line and plot scale stay fixed during draft edits, including model-strength edits. Values above the fixed display extent are marked with an arrow; their exact numeric multipliers are not clipped or normalized. Zero-update blocks and zero model strength cannot manufacture an update through dragging. Numeric zero-block edits remain ordinary settings and produce zero measured contribution.

Keyboard arrows select/adjust blocks; Shift adjusts by 0.1 instead of 0.01. Delete/double-click resets a single block. Separate buttons reset the selected block or all blocks to the immutable Default, or restore the last computed multiplier vector when its measured job/profile identity matches. Resets preserve supporting settings; an outer model strength below 1 can keep bars below the original line even after all block multipliers return to Default. Editing a resolved A/B slot clears its associated A/B record; resetting/restoring every block clears A/B assignments. All edits require a named save and fresh preparation before Copy.

Colour states and trial bounds come only from a matching role-informed computed receipt. Inactive blocks are grey, protected blocks blue, explained trial candidates green and review blocks amber. Without computed guidance, nonzero blocks require review. A colour is neither a semantic map nor a proven safe range; protecting character and clothing together can still leave the Sabrina/tights clash unresolved. Changing experiment priorities/method or computing again clears old trial guidance before a new receipt is accepted.
